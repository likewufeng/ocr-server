**部署方式**

生产环境：

```bash
docker compose up -d --build
```

本地 Docker 热更新开发：

```bash
docker compose -f docker-compose.yml -f docker-compose.dev.yml up --build
```

**服务器参数**

当前默认：

```bash
OCR_CPU_THREADS=8
OCR_TEXT_RECOGNITION_BATCH_SIZE=6
OCR_MAX_CONCURRENT_REQUESTS=1
```

`OCR_CPU_THREADS` 建议不要超过服务器实际 CPU 核数。并发量较大时，优先部署多个容器实例进行负载均衡，不建议直接提高单个 Paddle pipeline 的并发数，否则 CPU 争抢后单次响应通常会更慢。

目前仍保留图片方向检测和预处理图片落盘。若调用方能保证图片方向正确，关闭 `OCR_USE_DOC_ORIENTATION` 还能进一步减少耗时；排查图片落盘约占几十到几百毫秒，考虑到你的倒查需求暂时没有关闭。

验证已通过：五类证件解析回归、Python 3.9 编译、Compose 生产/开发配置及真实营业执照识别。
