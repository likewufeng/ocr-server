# 营业执照住所失败分析

本报告基于 63 张营业执照实时回归、对应 `request_id` 缓存、原始 OCR 坐标和原图抽查生成。

## 本轮修复

| 问题 | 修复方式 |
| --- | --- |
| 地址第二行与首行上下轻微重叠导致续行漏识别 | 地址候选允许轻微重叠，并优先选择与住所标签中心线最接近的首行 |
| `住`、`所`拆分标签被拼进地址尾部 | 将完整和拆分地址标签加入续行排除集合 |
| 副本页码 `（1）`被拼进地址 | 独立页码块和地址末尾明确的 `（1）`剔除 |
| 真实地址 `1幢（8）`被误删 | 仅删除明确副本页码，正文地址括号数字保留 |
| 地址括号全角/半角差异 | 评测时视为等价，不影响内容判断 |

## 回归结果

- 住所准确率：`88.89%`（56/63） -> `98.41%`（62/63）
- 全字段完全正确率：`79.37%` -> `87.30%`
- 住所失败：7 条 -> 1 条
